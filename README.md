# AI Smart Traffic Management System

An AI and Machine Learning based Smart Traffic Management System developed using:

- SUMO Traffic Simulator
- Unity Digital Twin
- Python
- YOLOv8
- Streamlit Dashboard

## Features

- Adaptive AI Traffic Signal Control
- Unity Traffic Simulation
- Live CCTV Monitoring
- YOLO Vehicle Detection
- AI Traffic Decision Engine
- Automatic Violation Detection (Upcoming)
- ANPR & Fine System (Upcoming)
